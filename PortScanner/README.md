# AHMEDCANN Port Scanner

## Project Name
AHMEDCANN Port Scanner

## Project Description
A Python-based cybersecurity tool that scans common TCP ports on an IP address and identifies open ports.

## Features
- Accepts an IP address as input
- Scans common TCP ports
- Identifies open ports
- Displays port numbers and associated services
- Provides clear scan results

## Installation
Python 3 is required.

Clone or download the project, then navigate to the PortScanner directory.

## Usage

Run:

python3 port_scanner.py <IP>

Example:

python3 port_scanner.py 127.0.0.1

# AHMEDCANN Banner Grabber

## Project Name
AHMEDCANN Banner Grabber

## Project Description
A Python-based cybersecurity tool that connects to a network service and attempts to retrieve its service banner and information.

## Features
- Accepts an IP address
- Accepts a port number
- Connects to the specified service
- Retrieves available service banners
- Displays results clearly
- Includes basic connection error handling

## Installation
Python 3 is required.

Navigate to the BannerGrabber directory.

## Usage

Run:

python3 banner_grabber.py <IP> <PORT>

Example:

python3 banner_grabber.py 127.0.0.1 8080

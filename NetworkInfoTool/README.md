# AHMEDCANN Network Information Tool

## Project Name
AHMEDCANN Network Information Tool

## Project Description
A Python-based cybersecurity utility that collects basic information about the local system and network configuration.

## Features
- Displays hostname
- Displays IP address
- Performs reverse DNS lookup
- Displays operating system information
- Provides results in a clear format

## Installation
Python 3 is required.

Navigate to the NetworkInfoTool directory.

## Usage

Run:

python3 network_info.py
